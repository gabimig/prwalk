# PRWalk preferences

How your agent gives you walkthroughs. Edit this file by hand, or ask your agent to change it. Plain words are fine.

- **Default level:** `overview`, unless the user asks for another one.
- **Opening:** the first sentence of the walkthrough says it is the high-level version, and that the user can ask in the chat for more detail on any part.
- **Going deeper:** detail comes on demand. Answer a question with `prwalk say`. When the user wants more detail on one part, add steps for that part only with `prwalk replace`, without raising the level of everything else.
- **After an answer:** the viewer stays paused until the user resumes it or asks you to carry on.
- **Narration language:** the language the user speaks to you.
